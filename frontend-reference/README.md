# Frontend reference

index.html is a clickable prototype. Open it in a browser. It is a visual and interaction reference only.

What it fakes: chat replies, accounts (browser storage only), the prompt counter, Word download (only works inside the original preview host), the microphone, subscription, and all template wording.
Do not copy its code. Rebuild in Next.js per AGENTS.md and map every feature through docs/FEATURE_MAP.md.
